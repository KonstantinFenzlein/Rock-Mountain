# Rock Mountain

Landingpage für eine fiktive Rockband mit dem Motto "Discover the best live music".

## Bereiche

- Home mit Hinweis auf den nächsten Auftritt
- Locations
- About
- Contact
- News und Album-Store

## Technologien

HTML5 · CSS3

## Projekt starten

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Rock-Mountain.git`
2. `index.html` im Browser öffnen.

## Hinweis

Band und Inhalte sind frei erfunden. Einige Icons stammen von externen Quellen (Quellenangabe im Seitenquelltext).
